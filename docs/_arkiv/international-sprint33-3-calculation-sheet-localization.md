# Sprint 33.3 — Calculation sheet localization + undefined-step fix

## Goal

Fix the remaining international render-layer bugs found in the W12x26 / AISC-ASCE run.

## Fixes

- Calculation sheet should use English labels when the run is clearly an international/AISC-ASCE run.
- Calculation sheet PDF/DOCX/LaTeX should use:
  - `CALCULATION SHEET`
  - `Document ID`
  - `Date`
  - `Given data`
  - `Assumptions`
  - `Step-by-step calculation`
  - `STEP 01`, `STEP 02`, etc.
  - `Results`
  - `Notes`
  - `Generated by PILAR. The calculation must be checked by a qualified professional before use.`
- Fixes the `UNDEFINED 01` / `UNDEFINED 02` bug in calculation sheet PDFs.
- Extends result-key cleanup:
  - `Lspan` → `Span, L`
  - `LTBregime` → `LTB regime`
  - `phibMpupperbound` → `φbMp upper bound`
  - `LTBzone` → `LTB zone`
  - `Lpapprox` → `Approx. Lp`
  - `Lrapprox` → `Approx. Lr`
- Adds extra polish for common Norwegian remnants in the international full report/result layer.
